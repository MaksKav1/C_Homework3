# Домашнее задание №3

## Условие задачи

Написать и отладить программу пересчета заданного в секундах временного интервала в часы и минуты.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать временной интервал в секундах:
   - `seconds = 10000`
3. Вычислить количество полных часов:
   - `hours = seconds / 3600`
4. Вычислить количество оставшихся минут:
   - `minutes = (seconds % 3600) / 60`
5. Вывести исходное количество секунд, количество часов и минут.
6. **Конец**
7.

## 2. Реализация программы

```c
#include <stdio.h>

int main()
{
    int seconds = 10000;
    int hours;
    int minutes;

    hours = seconds / 3600;
    minutes = (seconds % 3600) / 60;

    printf("Временной интервал: %d секунд.\n", seconds);
    printf("Количество полных часов: %d.\n", hours);
    printf("Количество минут: %d.\n", minutes);

    return 0;
}
```
